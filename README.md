# openfeature-provider-android-client

FeatBit Android Client SDK 的 OpenFeature Kotlin Provider。

当前处于设计阶段，尚未实现。

核心依赖已确定为正式发布的 `co.featbit:featbit-client-android:0.2.0`，所需核心能力已具备。
OpenFeature Kotlin `0.9.0` 仍是接口研究和竞态复现基线；完整状态保证所需的 G02 验收尚未通过。
